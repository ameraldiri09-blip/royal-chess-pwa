# ROYAL CHESS (PWA)

## طريقة النشر على GitHub Pages:
1. فك ضغط الملفات وارفعها جميعاً (`index.html`, `manifest.json`, `sw.js`, `icon.svg`, `icon-192.png`, `icon-512.png`) إلى مستودع (Repository) على GitHub.
2. افتح **Settings** ثم **Pages** في المستودع.
3. تحت **Branch** اختر `main` والمجلد `/ (root)` ثم اضغط **Save**.
4. افتح رابط الموقع على جوالك أول مرة بوجود الإنترنت، ثم اختر **إضافة إلى الشاشة الرئيسية (Add to Home Screen)** لتعمل اللعبة لاحقاً بدون إنترنت.
